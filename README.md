## Homelab
Three-node Docker Swarm cluster running Jellyfin, Navidrome, Vaultwarden, n8n, and a recursive DNS setup (AdGuard Home + Unbound) behind Traefik with keepalived HA. 
See more at [**homelab-iac**](https://github.com/Milisource/homelab-iac).
